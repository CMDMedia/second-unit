# Juggernaut XL v9 environment still

Generate one 1216 x 832 PNG using the visually approved 35-step, CFG 3.5, DPM++ 2M Karras setup. The API version feeds Second Unit; the UI version opens in ComfyUI. Second Unit saves each run in its own Environments folder and imports the still into the Second Unit Environments bin. This is one viewpoint, not multi-angle reconstruction.

## Two-pass environment still preview

The optional **Environment Stills Hyperreal** preset generates at 1344 x 768 and refines at 2016 x 1152 with a second diffusion pass. It is labeled **schema-only preview**: node and model checks are not visual approval. The reviewed 1216 x 832 recipe remains the default. Enable experimental/unproven presets to inspect the preview.

A separate still-image 4K upscale graph is not a supported video preset and is not included in the panel release.
